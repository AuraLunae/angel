# angel

## 開発思想
1. 悪魔で英単語で、単語データがサーバーにある構成で遅かったのをうけ、サーバーをサブとして使う方向を思いつきました
2. そこで、毎回、ページを読み込まなくてもいいと思い、完全オフラインで動作するページを開発しました
4. 語源データヘビーユーザーの自分としては、語源データが、あまちゃんだと思ったので、そこを改善しました

```
[端末]                                         [Supabase]
IndexedDB(akuma)                               auth.users(匿名ユーザー)
 ├ answers  ← 回答の全記録(端末だけ)            daily_counts(user_id, day, answers)
 ├ review   ← 復習状態(端末だけ)                      ▲
 ├ sets                                              │ RPC: sync_daily
 └ meta     ← session(トークン)/device/設定           │ RPC: get_ranking
        │                                            │
        └── sync.js が answers を日別に数えて ────────┘
            {"2026-11-01":12, ...} を送信
```

適当なので、解説しません  
ただ、オフラインにしてから、リロードができることは言っておきます。

## テスト

Node.js 18 以上で `npm ci` の後に `npm test` を実行します。テストは独立した仮想 IndexedDB を使い、実際の利用者データには接続しません。

手動追加はホームの「間違えた問題・おさらい」から、収録単語を英単語・意味・LEAP番号で検索します。すでにおさらい中の単語は変更せず、リストから外れた単語を再追加すると新しいおさらいとして開始します。追加した単語も通常の復習データとして端末に保存され、バックアップに含まれます。
